# Créditos dos sons

O tema sonoro **padrão** do Pherielium usa, para a interface (navegar, passar o mouse, selecionar,
voltar, modais, interruptores, iniciar jogo, abrir/fechar detalhe), os arquivos **"Deck UI …"**
da pasta `src/sounds/Phelierium Default/` (formato de sons de UI no estilo do Steam Deck).
O mapeamento está em `soundThemes.default` (`src/hooks/useSoundEffects.ts`).

> **Pendente:** a origem e a licença desses arquivos "Deck UI …" não estão registradas no
> repositório. Antes de publicar, anote aqui o autor, a fonte e a licença de cada pacote usado.

Os sons de chat, amizade, notificação, chamada, captura de tela e conquistas continuam sendo os do
próprio Pherielium (mesma pasta, arquivos `ui_*` e `Achievment_*`).
